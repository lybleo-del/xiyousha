# 西游杀（Xiyou Sha）

一款参考《三国杀》机制、以《西游记》为主题重新设计的**单机身份对战卡牌游戏**，纯前端实现，**可直接在手机浏览器上玩**。

---

## 一、设计总览

| 维度 | 设计 |
|------|------|
| 玩法核心 | 身份隐藏 + 角色技能 + 卡牌博弈（移植自三国杀） |
| 主题 | 取经路上，师徒降妖、群魔作乱、天庭斡旋 |
| 模式 | 单机，玩家 1 人 + AI 若干（4~8 人局） |
| 平台 | 移动端浏览器（响应式、触屏优化），无需安装、无需联网 |

## 二、身份系统（阵营与胜负）

身份随机分配且隐藏，仅**主公身份公开**。人数配置参考三国杀：

| 人数 | 主公 | 忠臣 | 反贼 | 内奸 |
|------|------|------|------|------|
| 4 | 1 | 1 | 1 | 1 |
| 5 | 1 | 1 | 2 | 1 |
| 6 | 1 | 1 | 3 | 1 |
| 7 | 1 | 2 | 3 | 1 |
| 8 | 1 | 2 | 4 | 1 |

- **主公**（唐三藏队核心，体力 +1）：消灭所有反贼与内奸。
- **忠臣**：保护主公，消灭反贼与内奸。
- **反贼（妖魔）**：击杀主公即获胜。
- **内奸**：先除掉其他所有人，最后与主公单挑取胜，方能独存。

**胜负判定**：主公阵亡 → 反贼胜（若仅剩内奸独存则内奸胜）；反贼与内奸全灭 → 取经队胜。

## 四、卡牌体系（约 80 张牌堆）

- **基本牌**：杀（攻击）、闪（抵消杀）、桃（回血/救人）
- **即时锦囊**：化斋（无中生有·摸2）、斗法（决斗）、顺手牵羊、过河拆桥、蟠桃盛会（群体回血）、群妖来袭（南蛮入侵）、飞沙走石（万箭齐发）、无懈可击
- **延时锦囊**：紧箍咒（乐不思蜀·跳过出牌）、天雷（闪电）
- **装备牌**：金箍棒/九齿钉耙/降妖宝杖（武器·扩大攻击范围）、莲花宝甲（防具·八卦判定）、千里马（-1坐骑）、火眼金睛甲（+1坐骑）

每张牌带花色（♠♥♣♦）与点数（A~K），用于判定（紧箍咒、天雷、莲花宝甲）。

## 五、回合流程

```
判定阶段 → 摸牌阶段(摸2) → 出牌阶段 → 弃牌阶段(手牌≤体力值)
```

- **判定阶段**：结算判定区的延时锦囊（紧箍咒/天雷）。
- **出牌阶段**：每回合限出 1 张「杀」（技能可突破），可使用任意锦囊/装备。
- **响应机制**：杀→闪、决斗/AOE→基本牌、锦囊→无懈可击（支持无懈连锁）、濒死→桃。

## 六、AI 设计

基于身份的启发式决策：

- **敌我判断**：主公公开；攻击过主公者「暴露」为反贼倾向；据此推断敌友。
- **行为优先级**：装备 → 化斋补牌 → 危急回血 → 群体锦囊（敌多于友时）→ 拆/顺敌人牌 → 紧箍咒控制 → 斗法 → 杀（优先残血敌人）。
- **响应**：几乎必闪/必救友方、对敌方有害锦囊用无懈保护友军。

## 七、技术结构

```
index.html        页面结构与开始界面
css/style.css     深色国风、移动端响应式
js/data.js        武将与卡牌数据、牌堆生成
js/engine.js      游戏引擎：身份、距离、伤害、濒死、胜负
js/flow.js        回合流程与卡牌结算（async/await 处理玩家响应）
js/ai.js          AI 决策
js/ui.js          渲染与触屏交互（Promise 对接异步引擎）
js/main.js        启动与选将界面
```

无构建步骤、无第三方依赖、无后端。

## 八、如何在手机上玩

**方式 A：本地直接打开**
1. 把整个项目文件夹传到手机。
2. 用手机浏览器打开 `index.html` 即可。

**方式 B：用 GitHub Pages 在线玩（推荐）**
1. 在仓库 Settings → Pages 中，将分支设为本分支、目录设为根目录。
2. 访问生成的网址，手机浏览器打开即玩，可「添加到主屏幕」当 App 用。

**方式 C：本地起服务器**
```bash
python3 -m http.server 8000
# 手机与电脑同一 WiFi，访问 http://电脑IP:8000
```
